¿Qué significa HTML?

HTML es el lenguaje de marcado que se utiliza para estructurar el contenido de una página web.

¿Para qué se utiliza CSS?

CSS se utiliza para definir la presentación y el aspecto visual de los documentos HTML.

¿Qué etiqueta se usa para crear un párrafo en HTML?

La etiqueta <p> se utiliza para crear un párrafo.
